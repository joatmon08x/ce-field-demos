# CompanyTicket plugin

Import from disk: **Customize → Browse Marketplace → Add Marketplace → Import from Disk** → this directory (`plugin/companyticket`).

The plugin includes:

- **MCP** `companyticket` — `describe_project`, `list_sprints`, `list_tickets`, `get_ticket`, `search_tickets`, `get_board`
- **Skill** `/standard-bug-fix` — pull an LY-000 ticket, then fix only that Ledgerly bug
- **Rule** `companyticket-tickets` — fetch the ticket before editing

The mock board is part of Ledgerly: [http://127.0.0.1:43173/companyticket](http://127.0.0.1:43173/companyticket).

Sprint **Fieldnote 26.8** has three cards: **LY-001**, **LY-002**, **LY-003**.
